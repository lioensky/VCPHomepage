# VCP RiverMemo Engine · 交互式算法实验室

独立静态科普演示，呈现 RiverMemo v2 的请求级动态虫洞、双场投影预算与向量池复用。Topology V3.1 与 AGS 是保留的底座名称，不是产品版本号。页面光点、分数、事件计数均为教学模拟，不调用生产 Rust 引擎、不代表检索准确率或性能测量。

## 访问地址

- 正式标准网址：https://www.vcptoolbox.com/vcp-rivermemo-engine
- 页面文件：[`vcp-rivermemo-engine.html`](vcp-rivermemo-engine.html)
- 旧网址 `/vcp_wave_v8_engine` 和 `/vcp_wave_v8_engine.html` 在 Vercel 上永久跳转至新网址。
- 本地在仓库根目录启动开发服务后，访问 http://localhost:3000/vcp-rivermemo-engine.html 。无扩展名标准网址由部署平台的重写规则提供。

## v2 教学边界与验证

- 虫洞实验缩小为 6 条历史边、总邻居名额 3、动态席位 2；生产默认总邻居名额仍为 20，动态不同目标预算为 4096。候选、入选、注入、尾部提升分别显示。
- 双场实验用 12 个节点展示 K=1、3、256、0；生产默认 K=256。以 Spike 活跃核心为骨架，两场分别沿真实正权重出边按本场质量维护前沿，至质量目标、预算或前沿边界停止，不再采用全局质量 Top-K。K=0 仅取消数量上限。
- 教学核心固定为节点 1，节点 11 是高质量孤岛、节点 12 为零质量拒绝项。稠密交叉边不重复占位，两场名单各自投影、读取并集去重。示例每对方向均有独立真实边，不能据此推断任意单向可达路径均可反向返回核心。核心总数超过 K 的生产策略尚未在本演示定义。
- 池内预置两个节点代表金字塔等前序阶段已加载向量；重复读取只补差集。载荷统计仅为 3072 维 FP32，不含容器开销。
- 切换 K 开始新的教学请求；释放后不允许旧观测继续读出。真实实现还需要数据库代际校验、共享引用生命周期管理，浏览器实验没有模拟数据库事务。
- 顶部与首屏 RiverMemo 白皮书入口为 `/?page=docs&doc=rivermemo-topology-v3`，由现有阅读器加载 [`rivermemo-topology-v3.md`](../src/docs/rivermemo-topology-v3.md)，不是 Learn VCP 总白皮书。
- 仓库根目录运行交互回归：[`test-rivermemo-scenes.cjs`](../scripts/test-rivermemo-scenes.cjs)。覆盖全部按钮、场景绘制、可见性调度、时钟暂停恢复及 v2 模型契约。
