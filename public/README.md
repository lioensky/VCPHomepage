## 算法与教学边界

- 产品／架构名称为 RiverMemo V3／Topology V3。读出与管线标识中的 v2.2 是实现编号，不表示产品仍为 V2。版本依据与完整契约见[当前白皮书](../src/docs/rivermemo-topology-v3.md)。
- 四项分为基础、路径、图与锚。场共振先封顶再乘标量支持，不降低原始查询分；路径不乘 Ω，图乘 Ω，二者共享默认 0.08 预算；锚独立限额 0.10。
- 锚采用默认 0.05 激活、0.20 饱和的绝对阈值；纯隐式强度最多 0.035。角色用于解释，不能代替显式精确身份或决定奖励倍率。
- 评分模型直接接收预设证据标量，不模拟原生候选生成、向量点积、完整接触幅度聚合或数据库事务。终章角色同样为预设，不是实体身份识别结果。
- 虫洞图缩小为 6 条历史边、3 个总名额、2 个动态席位。生产默认总名额 20、不同目标评估预算 4096。尾残差仅增加路由资格，不制造种子、历史边或额外电流。
- 双场实验采用 30 节点、4 个共享核心及两个根流域；每通道先轮转最多两个外圈机会，再以最多四个机会为批次做简化收益调度。沿真实正边维护负对数距离，不能跳过桥接点。
- K 限制双场含核心的去重并集；核心超过正预算显式失败。K=0 只取消数量限制，质量与工作边界仍保留。机会不保证获得新向量。
- 两场各自接纳与累计质量；交汇 ID 只扣一次共享票。缺失向量不全库补位，有效向量子集不保证连通。
- 请求池重复读取只补差集；释放不清除常驻图。载荷估算按 3072 维 FP32，不含容器开销，也不是整个请求内存上限。
- 高 Ω 不证明主题正确或因果成立；合成测试通过不等于真实召回率、排名或延迟保证。
